GRAPHICAL REPRESENTATION - INTEGRATED

Run from this folder:
  python -m pip install matplotlib
  python main.py

Log in as Admin or Faculty, open Analysis, then select "Graphical Representation".
Charts: Subjects, Students, Semesters, Grades, Pass / Fail.
Click "Refresh Graphs" after editing marks/results.
Graphs use live data from the existing SQLite database; no sample marks are substituted.
The existing text analysis and standalone analysis_graphs.py remain available.
